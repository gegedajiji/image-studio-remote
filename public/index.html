文生图

POST /v1/images/generations

curl https://image.twotop.icu/v1/images/generations \
  -H "Authorization: Bearer sk-img-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "一张极简产品海报，柔和自然光，无文字",
    "quality": "2k",
    "size": "1024x1024",
    "output_format": "jpeg",
    "n": 1
  }'
图生图

POST /v1/images/edits

curl https://image.twotop.icu/v1/images/edits \
  -H "Authorization: Bearer sk-img-xxx" \
  -F "prompt=把图片改成 iOS 风格产品摄影，背景干净" \
  -F "quality=2k" \
  -F "size=1024x1024" \
  -F "output_format=png" \
  -F "image=@source.png"
参数
prompt
必填，2-4000 字。
quality
1k / 2k，也兼容 standard / high。
size
1024x1024、1536x1024、1024x1536。
output_format
jpeg、png、webp。
n
生成张数：1、2、4。
